# Email Spam Detection Using Naive Bayes

## Project Overview
This project focuses on classifying emails or messages as **Spam** or **Not Spam (Ham)** using the Naive Bayes classification algorithm. It uses Natural Language Processing (NLP) techniques to analyze text and identify unwanted messages.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Natural Language Processing (NLP)
- Jupyter Notebook


## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Text Vectorization using CountVectorizer / TF-IDF
4. Splitting data into Training and Testing sets
5. Training the Naive Bayes classifier
6. Model Evaluation using Accuracy, Confusion Matrix and Classification Report
7. Spam and Ham Prediction

## Key Features
- Identifies spam and legitimate emails/messages.
- Uses text classification techniques.
- Provides automated spam detection.
- Helps reduce unwanted messages.


## Conclusion
This project demonstrates how the Naive Bayes algorithm can be used for text classification and spam detection. It provides practical experience in data preprocessing, NLP, classification, and model evaluation.
